**Pay-Cord** هو بوت ديسكورد عربي متكامل لنظام الكريدت (العملات الافتراضية)، مصمم ليوفر تجربة مالية سلسة وسريعة داخل السيرفرات مع لوحة تحكم وموقع إلكتروني رسمي.

---

## ✨ المميزات الأساسية (Features)

- 💰 **نظام كريدت متطور:** عرض الرصيد الشخصي أو رصيد أي عضو بسهولة.
- ⚡ **تحويلات فورية وآمنة:** تحويل الكريدت بين الأعضاء مع نظام حماية وضريبة قابلة للتخصيص.
- 🎁 **مكافآت يومية (Daily):** استلام جوائز ومكافآت يومية لتشجيع التفاعل في السيرفر.
- 🌐 **موقع ولوحة تحكم:** إدارة الرصيد ومتابعة السجلات عبر الموقع الرسمي.
- 🇸🇦 **دعم كامل للغة العربية:** واجهة أوامر وردود واضحة باللغة العربية.

---

## 🛠️ الأوامر الأساسية (Commands)

| الأمر (Command) | الوصف (Description) |
| :--- | :--- |
| `/credits` | عرض رصيد الكريدت الخاص بك أو رصيد عضو آخر |
| `/transfer` | تحويل مبلغ من الكريدت إلى عضو آخر في السيرفر |
| `/daily` | استلام المكافأة اليومية المجانية كل 24 ساعة |
